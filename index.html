Política de Privacidade

1. Responsável pelo Tratamento

A PorpamTech é a entidade responsável pelo tratamento dos dados pessoais recolhidos através deste website, de acordo com o Regulamento Geral de Proteção de Dados (RGPD).

2. Dados Recolhidos

Recolhemos apenas os dados fornecidos voluntariamente através do formulário de contacto: nome, email, assunto e mensagem. Não utilizamos cookies de rastreamento nem recolhemos dados de navegação.

3. Finalidade

Os dados recolhidos são utilizados exclusivamente para responder às solicitações dos utilizadores e para comunicação relacionada com os nossos serviços.

4. Conservação dos Dados

Os dados pessoais são conservados apenas pelo período necessário para cumprir a finalidade para a qual foram recolhidos, sendo eliminados após esse período.

5. Direitos do Titular

Tem direito a aceder, retificar, apagar, limitar ou opor-se ao tratamento dos seus dados pessoais. Para exercer estes direitos, contacte-nos através do email info@porpamtech.com.

6. Segurança

Implementamos medidas técnicas e organizativas adequadas para proteger os seus dados pessoais contra acesso não autorizado, perda ou destruição.
